# OJC — Organización Jurídica Contable

Primera versión del sitio web corporativo de OJC, preparada para GitHub Pages.

## Antes de publicar
1. Abrir `script.js` y reemplazar `whatsapp` por el número real en formato internacional, sin `+`, espacios ni guiones.
2. Reemplazar los enlaces `#` de redes sociales.
3. Actualizar teléfono, correo, dirección y horario en las páginas.
4. Sustituir los textos provisionales si OJC desea una redacción jurídica/comercial definitiva.
5. Agregar las fotografías del equipo en la sección correspondiente.

## Publicación
El proyecto usa HTML, CSS y JavaScript puro, por lo que funciona directamente en GitHub Pages sin servidor.
